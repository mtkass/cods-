# Лабораторная работа: Сравнение методов классификации

## Описание
В данной работе проводится сравнение трех алгоритмов машинного обучения: 
- Дерево решений (Decision Tree)
- Метод опорных векторов (SVM)
- Случайный лес (Random Forest)

## Датасет
Данные взяты с сайта KEEL
Задача — бинарная классификация.

## Что сделано
- Загрузка и первичный анализ данных (pandas)
- Стандартизация признаков
- Разделение на обучающую, тестовую и валидационную выборки (5/3/2)
- Подбор гиперпараметров для трех моделей:
  - Дерево решений: alpha, критерий (entropy/gini)
  - SVM: kernel, C, gamma, coef0, degree
  - Random Forest: число деревьев, критерий
- Оценка моделей по метрикам: Accuracy, Precision, Recall, ROC-AUC
- Эксперименты с обогащением и стратификацией выборки

## Результат
Выбрана лучшая модель на основе метрики ROC-AUC. Проведен сравнительный анализ влияния предобработки на качество классификации.

## Используемые библиотеки
- Python (pandas, numpy)
- scikit-learn
